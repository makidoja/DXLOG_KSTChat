# DXLog KST Chat Bridge with AirScout v2.4.3

## Changes since v2.3.3

Version 2.4.3 is a contest-workflow, DXLog integration and reliability update. It adds unread-message handling, per-band macro profiles, improved filtering, station notes, a one-click contact workflow, better AirScout diagnostics and more reliable DXLog/rotator control.

## Unread directed messages

- Added a compact **Msg** column to the station list.
- Directed messages that have not yet been viewed show an orange unread-count indicator.
- Selecting the station or opening its conversation marks the messages as read.
- Unread counts are session-based and reset when reconnecting or changing KST room.
- Incoming messages update chat, activity and unread counts only.
- Incoming messages no longer select the sender, change the map trace, alter the AirScout path or move the rotator.

## Per-band macro profiles

M1–M4 can now be stored separately for:

- General
- 50/70 MHz
- 144/432 MHz
- 1296 MHz
- Microwave
- EME

The active macro set follows the current DXLog band automatically. The EME KST room selects the EME profile. Right-clicking M1–M4 edits the currently active macro set.

Existing general macros are retained as the initial fallback for newly created band profiles.

## Need filter

- Added a **Need** checkbox to show stations not yet worked on the current DXLog band.
- The Need filter can be combined with the existing Distance and AirScout opportunity filters.
- Watched stations remain visible even when they do not match the Need filter.
- Worked-state changes update the filtered list without requiring a complete list rebuild.

## Prepare Contact workflow

The station right-click menu now includes **Prepare contact**.

This workflow:

1. Selects the station and clears any previous prepared-station highlight.
2. Marks its directed messages as read.
3. Inserts the callsign into the active DXLog QSO entry line.
4. Allows DXLog to perform its normal callsign lookup.
5. Overwrites DXLog's **Loc/Grid/QRA** field with the latest locator advertised by the station on KST.
6. Requests the AirScout path calculation without bringing the AirScout window in front of DXLog.
7. Opens or updates the KST map.
8. Turns the rotator when **Turn rotator on click** is enabled.
9. Returns focus to the KST custom-message field after the DXLog update has completed.

The separate **Show path in AirScout** command remains available when the operator deliberately wants AirScout brought to the foreground.

## Latest KST locator takes priority

The bridge now treats the current KST locator as the latest known QRA for the station.

After DXLog completes its normal callsign/database lookup, the bridge explicitly overwrites the active Loc/Grid field with the locator received from KST. This prevents an older locator stored in DXLog from replacing the station's current portable or contest QRA.

This applies to:

- manual station clicks;
- **Prepare contact**;
- **Turn rotator** commands.

## Rotator integration

- Left-clicking a station can now update DXLog and turn the rotator when **Turn rotator on click** is enabled in the Map window.
- **Prepare contact** follows the same rotator setting.
- Rotator movement is delayed until DXLog has accepted the callsign and the KST locator has been applied.
- This prevents Ctrl+F12 acting on the previous or incomplete log-entry contents.
- Added **Turn rotator to N°** to the station right-click menu when a valid locator and bearing are available.
- Rotator handler detection tolerates compatible DXLog method-name changes and retains Ctrl+F12/direct-azimuth fallbacks.
- The **Turn rotator on click** preference is saved and restored when the Map window is reopened.
- Rapid or double clicks on the same callsign are de-bounced to prevent duplicate entry-line and rotator commands.

## Single-selection behaviour

Preparing or selecting a new contact now clears the previous prepared/highlighted station. Only the current station remains selected in the KST list.

## Persistent station notes

- Add or edit a note from the station right-click menu.
- Clear an existing note from the same menu.
- Notes are saved between bridge sessions.
- Notes appear in station tooltips.

Example uses include preferred frequencies, polarisation, previous sked details or station-specific operating notes.

## AirScout health reporting

- While the map is open, the bridge reports a stale aircraft feed after 45 seconds without a successful live-aircraft update.
- Temporary HTTP failures or empty responses retain the last valid aircraft positions instead of clearing the map.
- The selected map trace remains independent of aircraft updates.
- **Prepare contact** sends `ASSETPATH` only, so AirScout calculates the path without jumping in front of DXLog.
- **Show path in AirScout** continues to use `ASSHOWPATH` when explicitly selected.

## Performance diagnostics

The performance window now includes:

- KST user count;
- visible station count;
- AirScout result count;
- AirScout reply time;
- aircraft-feed update time and status;
- KST refresh time;
- map-render time;
- current UI delay;
- maximum recorded UI delay.

Open the diagnostics by right-clicking the bridge status line.

## DXLog entry-line reliability

- Callsign-control lookup is now recursive, improving compatibility when DXLog nests the entry field inside another control.
- The DXLog main form is resolved more robustly before callsign, locator or rotator operations.
- Entry-line updates are queued until after right-click menus close, preventing the menu from stealing or redirecting the update.
- Focus returns to the KST message field only after the DXLog callsign and locator update is complete.

## Retained v2.3.3 features

Version 2.4.3 retains the major features introduced before v2.4, including:

- graphical AirScout indicators: green for **NOW**, orange for approaching opportunities;
- selectable worked-band columns with green ticks;
- persistent station watchlist;
- AirScout opportunity filters and automatic sorting;
- AirScout alerts;
- aircraft trails;
- rich AS and station tooltips;
- additional macro tokens;
- persistent selected map path and aircraft overlays;
- map label collision avoidance;
- separate right-click menus for the title bar, station list, messages, macros, map and status area;
- protection against DXLog's underlying log-entry menu appearing alongside the KST Bridge menu.

## Compatibility and upgrade notes

- Existing KST, AirScout, colour, room, watchlist and general macro settings are retained where possible.
- Existing general macros remain available as the fallback for newly created per-band profiles.
- Station notes, per-band macros and the saved rotator preference are stored in the bridge settings.
- AirScout remains the aircraft-position and path-calculation engine.

The normal data path remains:

```text
Aircraft feed → AirScout → UDP 9872 / HTTP 9880 → KST Bridge
```
